## 📌 Proyectos destacados

### 🧠 SmartBusiness AI
Sistema web orientado a la gestión de negocios con enfoque full stack. Incluye módulos de clientes, productos, ventas, dashboard y autenticación.

**Tecnologías:** React, Vite, Django, DRF, JWT, SQLite/MySQL  
**Enfoque:** dashboard, roles, CRUD, API REST y reportes.

---

### 🏔️ InkaRise EE3
Videojuego 2D desarrollado en Godot con temática inca. Implementa mecánicas trigonométricas y vectoriales como rebote, rayo detector, guía de proyectiles, niveles, mapa y HUD.

**Tecnologías:** Godot, GDScript, diseño 2D  
**Enfoque:** trigonometría, vectores, RayCast, rebote, UI y experiencia de usuario.

---

### ✈️ Lucky Air / Yunnan Experience
Sitio web turístico desarrollado como proyecto frontend, con estructura HTML, CSS, maquetación responsive, secciones visuales y enfoque en experiencia de usuario.

**Tecnologías:** HTML, CSS, JavaScript, GitHub Pages  
**Enfoque:** maquetación, diseño responsive, Flexbox, Grid y presentación visual.
